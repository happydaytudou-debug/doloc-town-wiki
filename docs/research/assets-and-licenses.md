Audit date: 2026-08-13

No approved visual asset files were supplied with the Level 1–3 package.

The source notes mention that Steam and the official YouTube channel may provide visual references, but they do not include downloaded assets or an explicit reuse license. Therefore no screenshot, logo, thumbnail, video still, or other game image is approved for site use at this stage.

No open-source icon package has been selected. Before adding one, record its project name, source URL, exact license, version, files used, and required attribution here.
