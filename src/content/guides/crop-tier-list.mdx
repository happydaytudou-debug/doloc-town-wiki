## Before Using a Tier List

Crop rankings depend on the dataset, game version, and the player’s goal. The linked community pages provide broader context but do not supply a complete crop table or shared ranking method. <SourceRef id="S2" /> <SourceRef id="S4" />

<GuideWarning>A tier label without stated criteria would be opinion presented as fact. This page therefore avoids S-, A-, or lower-rank assignments.</GuideWarning>

## Useful Ranking Criteria

A useful comparison should separate profit, growth time, access stage, input burden, processing value, and any gene interaction shown in the current version. Visible weighting lets readers judge whether a ranking fits their goal.

## Relationship to other crop guides

Most Profitable Crops addresses the narrower economic question, while Gene System covers possible modifiers. Compare those pages with the values displayed in your own game before combining their conclusions.

## Version discipline

Any ranking must carry a version or date because balance changes could alter inputs and conclusions.
