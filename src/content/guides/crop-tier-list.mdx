No crop tiers are published because the imported evidence contains no exact dataset or approved ranking method. The supplied links are research starting points only. <SourceRef id="S2" /> <SourceRef id="S4" />

## Required ranking criteria

A future tier list must separate profit, growth time, access stage, input burden, processing value, and any verified gene interaction. Weighting choices must be visible so readers can judge whether the ranking fits their goal.

## Relationship to other crop guides

Most Profitable Crops should answer a narrower economic question using reproducible values. Gene System should explain verified modifiers. This page can combine those results only after their evidence is stable.

## Version discipline

Any ranking must carry a version or date because balance changes could alter inputs and conclusions.
